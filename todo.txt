# Vizha OS – Enterprise Event Management ERP
# 100% Modern Full-Stack TypeScript & React Architecture

## Stack
- Framework: Next.js 15 (App Router)
- UI Library: React 19
- Language: TypeScript 5+ (Strict Mode)
- Styling: Tailwind CSS
- Database & Backend: Supabase (PostgreSQL) + Prisma ORM + @supabase/server
- State: React Context + LocalStorage Persistence

## Modules & Capabilities
1. Instant RBAC Quick-Switcher (Super Admin, Event Manager, Sales Exec, Accountant, Operations, Client, Vendor)
2. CRM Leads Pipeline (7-stage Kanban board with 1-click lead to client/event conversion)
3. Event Productions & Staging (Minute-by-minute Run of Show with cue notes and checklists)
4. Client Account Master Records & GSTIN
5. Partner Venues & Vendor Subcontractors
6. 18% GST Quotation Builder & Proposal View
7. 18% GST Milestone Tax Invoices & Partial Payment Recording
8. Production Budget & Expense Approvals
9. Equipment Fleet Inventory Management
10. Guest RSVPs, Table Allocations & Gate Check-in
11. Digital Anti-Fraud Ticketing & Live QR Optical Scanner
12. Printable Boarding-Pass Style Badges
13. Executive Financial Reports & P&L Analysis
14. External VIP Client & Vendor Partner Portals

Status: 100% TypeScript & React Rebuild Complete. Zero PHP dependencies.
